# WEEKLY AUDIT CHECKLIST — 40 minutes — v30

> Workflow C. Run by CRITIC then OPS. This is what keeps year 7 alive.

## Audit prompts (to CRITIC, then OPS)
```
Weekly audit v30
Review:
- Did we obey Constitution?
- Did anything important stay only in chat?
- Which outputs already feel generic or off-principles?
- What vendor/model risk appeared?
- What should be frozen, deleted, or rewritten?
- What one process change would reduce rework next week?
Produce: audit note for /AUDITS and an updated State Pack.
```

## Steps
1. Update `STATE-PACK.md` capacity + one objective (3 min).
2. CRITIC on last week's artifacts + the whole system (25 min).
3. OPS converts findings into **one** process fix (10 min).
4. File note in `AUDITS/` + update State Pack (2 min).

## Checklist
- [ ] Constitution obeyed all week?
- [ ] Nothing important stayed only in chat?
- [ ] Any output drifting generic/off-principles?
- [ ] New vendor/model risk?
- [ ] Anything to freeze, delete, rewrite?
- [ ] One process change identified and filed?

## Definition of done
- [ ] `AUDITS/YYYY-MM-DD.md` exists
- [ ] State Pack current
- [ ] ≤1 process change selected (not a pile of ideas)

## Failure path
Capacity=low → do steps 1 and 4 only; flag freeze if any drift signal.
