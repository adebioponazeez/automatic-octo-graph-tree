# DAILY CHEAT SHEET — 25 minutes — v30

> One page. Survival cadence (Workflow B). If capacity is **low**: maintenance only, no new initiatives.

```
Daily loop
1. 3 min: Update STATE-PACK.md (capacity, one objective, one risk)
2. 15 min: One operator only. One artifact only.
3. 5 min: CRITIC if the artifact will be used externally or in code
4. 2 min: Write decision/artifact into canonical store
Done. No extra chats.
```

## Pick the operator (only one)
- New direction / trade-offs / what must remain true → **STRATEGIC**
- Architecture, contracts, code → **SOFTWARE**
- Copy, offers, content → **PRODUCT-CONTENT**
- SOPs, cadence, resilience → **OPS**
- Reality check before shipping → **CRITIC**

## Guardrails
- One objective today. Name it.
- Anything that matters in 90 days → file it the same day.
- If you can't state the objective in one sentence → **FREEZE** (see `FREEZE-CHECKLIST.md`).
- Chats are disposable. Files are not.

## Time budget
- Normal: 25 min
- Bad week (low/freeze): 15 min maintenance only
