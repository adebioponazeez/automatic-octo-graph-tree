> These document known failure modes so CRITIC and operators recognize them.

## Known failure families
1. **Generic strategy** — reads like it could apply to anyone; no trade-offs, no testable done → `bad-generic-strategy.md`
2. **Fake 24/7** — presents a chatbot as an unattended production system; no A/B/C/D split, no monitoring/recovery → `bad-fake-247.md`
3. **Hype copy** — invented results, testimonials, numbers, or urgency without verified proof → `bad-hype-copy.md`
4. **Missing assumptions** — implicit context treated as known; no expiry, no failure modes, no META → `bad-missing-assumptions.md`
