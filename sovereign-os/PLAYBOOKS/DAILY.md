# PLAYBOOK: DAILY — Survival Cadence — v30

> Human time box: **25 minutes**. If capacity is low: maintenance only, no new initiatives.

```
Daily loop
1. 3 min: Update STATE-PACK.md (capacity, one objective, one risk)
2. 15 min: One operator only. One artifact only.
3. 5 min: CRITIC if the artifact will be used externally or in code
4. 2 min: Write decision/artifact into canonical store
Done. No extra chats.
```

## Rules
- One operator. One artifact. One objective.
- If capacity is **low** or **freeze**: maintenance only (update State Pack, file artifacts, no new work).
- Anything important goes into the canonical store the same day. Chats are disposable.

## Time budget
- Normal day: 25 min
- Bad week (capacity=low): 15 min — OPS redesigns the loop, kill anything not in the 90-day done.
